# 🎮 Website de Minigames com Flask

Este projeto foi desenvolvido como atividade escolar, mas decidi ir além e explorar mais funcionalidades do **Flask** e do desenvolvimento web em geral.  
O site reúne alguns **minigames clássicos**, como **Forca** e **Jokenpô**, com uma interface simples e responsiva.

## 🚀 Funcionalidades

- **Flask com HTML dinâmico** para renderização das páginas.  
- Estrutura organizada usando **Blueprints**.  
- **Responsividade** para diferentes dispositivos.  
- Comunicação entre **front-end (JavaScript)** e **back-end (Flask)** usando **funções assíncronas (async/await)** e **requisições HTTP**.  
- Minigames disponíveis:  
  - 📝 Forca  
  - ✊✋✌️ Jokenpô  

## 🛠️ Tecnologias Utilizadas

- [Python](https://www.python.org/) + [Flask](https://flask.palletsprojects.com/)  
- [HTML5](https://developer.mozilla.org/docs/Web/HTML)  
- [CSS3](https://developer.mozilla.org/docs/Web/CSS)  
- [JavaScript](https://developer.mozilla.org/docs/Web/JavaScript)
